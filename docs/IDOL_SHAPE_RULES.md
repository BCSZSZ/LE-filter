# 神像按形状合并目标

2026-10-24，按玩家明确约定：**每个BD、每种神像类型，在同一个目标数量分组内最多一条规则。**“命中一项”与“命中两项”分别是两个分组，不合并提示档位。

## 生成方式

- 一项层：同BD、同形状的普通目标词缀取并集，至少命中一项，使用开始提示。
- 两项层：使用同一目标池，至少命中两项，使用灵感提示，仍排在一项层前。不枚举词缀配对。
- 两层各自合并来源底材：一项层取`bases`并集，两项层取`pair_bases`并集，缺少后者时沿用该来源的`bases`。某来源明确不限底材时，该层保持不限。
- 只处理有普通目标的来源组；空目标、仅附魔／腐化参考、BD未提供的神像类型均不补规则。普通目标仍限冻结类别0／5，附魔4和腐化6不加入普通池。
- 合并只发生在同一个BD内，不把主副BD词缀凑成两项。通用神像、暗金神像、祭坛和装备策略保持各自逻辑。
- 合并发生在生成阶段；原始需求、来源、候选层与两项层底材记录、个人模版及保存方案均不改写。原生小型／中型神像类型仍分别处理。

同形状原先的“底材A只收词缀甲，底材B只收词缀乙”归并后，成为“所选底材并集＋目标词缀并集”。这是此次明确采用的新收集范围，不是保持旧匹配集合不变的压缩。

## 57／59的合并

玩家文件的57与59都属于主BD的“一项普通目标”分组，类型均为巨型神像`IDOL_1x4`。合并为一条，底材为巨型暗影／异端巨型暗影，普通目标池为：

| 词缀 | 普通槽位 |
|---|---|
| 游侠反曲几率与弓箭伤害 | 前缀 |
| 投掷物理伤害 | 后缀 |
| 提高护甲粉碎持续时间 | 后缀 |

对应的原30／32也合成一条“两项普通目标”灵感规则。三项目标池不表示三种配对都能自然出现；普通神像固定一前一后，合法普通组合是上述前缀分别搭配任一后缀，两个后缀不能同时占据两个普通槽。[官方神像说明](https://support.lastepoch.com/hc/en-us/articles/46361996303387-Idols)

例如巨型暗影神像只有“提高护甲粉碎持续时间”时进入开始层；同时带有“游侠反曲几率与弓箭伤害”时进入灵感层。

若某形状的目标池只有前缀或只有后缀，不生成普通两项层。例如Allie小型神像的“虚空抗性与召唤物虚空抗性”“物理抗性与召唤物物理抗性”同为后缀，仅保留一项层；没有为凑两项而补入来源外的前缀。
