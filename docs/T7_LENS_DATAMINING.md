# 崇高装备 T7 概率与三种镜片：1.5.2.2 游戏文件调查

调查日期：2026-10-17。玩家确认的主场景：**100级区域、满级观星台、普通崇高预言**。

本轮读取本机原生生成代码与实际资源配置，再重建概率模型。百分比是**文件静态还原后的计算**，未启动游戏做掉落采样，也未读取线上服务器运行态。

## 可以精确复现的主结果

**部位与词缀权重会影响概率，所有崇高装备没有一个通用常数。** 主表采用游戏真实的“普通崇高戒指预言”：奖励ID121，100级，全部42种合格普通戒指词缀，不按BD筛选，也没有把每条词缀都假定为相同概率。

分母是该预言生成的每件戒指，均保证崇高。1T7、2T7分别指**恰好一条、恰好两条T7**，T8不计入。

| 镜片 | 恰好1T7 | 恰好2T7 | 至少2T7，含三／四T7 | 恰好双T7相对无镜片 |
|---|---:|---:|---:|---:|
| 无镜片 | 22.414085% | 0.045479% | 0.045511% | 1倍 |
| Lens of Quality／优质 | 27.327600% | 0.478586% | 0.479348% | 10.52倍 |
| Lens of Origin／提升前缀 | 25.740373% | 0.346888% | 0.347376% | 7.63倍 |
| Lens of Finality／提升后缀 | 25.592660% | 0.337836% | 0.338322% | 7.43倍 |

按至少双T7，无镜片约2,197件一件；优质约209件一件。这是长期平均期望，不是保底次数。

**在这个戒指预言中，追任意双T7，优质收益最高；追前缀／后缀上的T7，对应定向镜片更强。** 后者应看以下概率：

| 镜片 | 至少一个前缀T7 | 至少一个后缀T7 |
|---|---:|---:|
| 无镜片 | 11.729614% | 10.760310% |
| 优质 | 14.618682% | 13.507605% |
| 提升前缀 | 16.273345% | 10.039284% |
| 提升后缀 | 10.974551% | 15.189231% |

这仍是对应侧的任意词缀，不是指定BD词缀命中率。定向镜片可能降低另一侧最终获得T7的机会，因为镜片先产生的崇高词缀会影响之后的“保证崇高”步骤。

## 镜片实际升阶机制

本机资源 `Prophecy Data` 的三个字段均为 `0.2f`：

```text
originLensPrefixTierUpgradeChance = 0.2
finalityLensSuffixTierUpgradeChance = 0.2
qualityLensRandomAffixTierUpgradeChance = 0.2
```

实际代码先做一次20%检定；成功后按当前阶数权重，从合格词缀中**选一条**，随机增加1–3阶，最高T7。不是整件装备每条词缀各做一次20%检定。

| 当前阶数 | 被选中的权重 | 选中并触发后，升到T7的概率 |
|---|---:|---:|
| T1 | 0.01 | 0 |
| T2 | 0.05 | 0 |
| T3 | 0.1 | 0 |
| T4 | 0.5 | 4/9，约44.44% |
| T5 | 1 | 7/9，约77.78% |
| T6 | 2 | 100% |
| T7 | 0，排除 | 已是T7，不参与选择 |

增加阶数原始权重为 `+1 : +2 : +3 = 1 : 1.5 : 2`，归一化概率为 `2/9、1/3、4/9`。

- Quality选当前低于T7的词缀；实际入口跳过神像。
- Origin选低于T7、未封印的前缀。
- Finality选低于T7、未封印的后缀。
- 前后缀谓词检查的是 `sealedAffixType`，不是 `specialAffixType`。不能据此声称实验／冠军词缀因特殊类别而被排除。
- 单次镜片升阶最多新增一条T7。

对已进入镜片步骤的固定装备，候选集合S、上表选择权重w、到达T7机会h满足：

```text
P(镜片步骤额外产生一条T7) = 0.2 × Σ(w_i × h_i) / Σw_i
```

候选为空时为零。例如 `[T7,T6,T5,T5]` 用优质：

```text
0.2 × (2×1 + 1×7/9 + 1×7/9) / (2+1+1) = 17.777778%
```

**17.78%是给定装备状态的转移概率，不是崇高预言最终双T7率。** 主表0.478586%已对自然生成与之后保底步骤积分。

[官方1.5镜片说明](https://lastepoch.com/1-5/patchnotes/#lenses)也说明Quality是随机词缀升阶；[Tunklab 1.5.2原始预言数据](https://lastepoch.tunklab.com/_next/static/chunks/24lkeki6rom7u.js)的三个20%字段与本机资源一致。暗金另有LP参数1.15，本报告没有将它用于T7。

三者只作用于相应预言奖励，**不提升全地图自然掉落**。每个预言槽只有一个镜片，不能将三者叠装到同一奖励；此边界与[官方2026-09-22阵营更新](https://forum.lastepoch.com/t/faction-updates-coming-to-last-epoch-october-1/81759)一致。

## 自然T6、T7的基础公式

`RollTier`先生成T1–T5。100级时累积阈值依次为 `T5=.14、T4及以上=.32、T3及以上=.56、T2及以上=.84`，故未做崇高升级前，T1–T5概率为 `16%、28%、24%、18%、14%`。只有先到T5，才尝试自然T6，再尝试T7。

令w为词缀在该装备类型上的 `GetWeighting`，先采用部位专用权重覆盖项；令 `r=clamp(1−w,0,1)`。每次升阶独立以r概率用较高的“稀有词缀”机会；积分后：

```text
a = clamp(M × [0.045 + (0.096−0.045)×r], 0, 1)
b = clamp(M × Q × [0.066 + (0.120−0.066)×r], 0, 1)

P(自然T6或以上 | 此词缀) = 0.14 × a
P(自然T7 | 此词缀)       = 0.14 × a × b
```

无观星台为M=1、Q=1；本机满级观星台为M=1.5、Q=2。**M同时乘T5→T6和T6→T7两步，Q只乘第二步。** 不能把整件物品的双T7概率直接乘二。

例如w=1的一条普通词缀，无加成自然到T7为0.041580%；满级观星台为0.187110%。这是一条词缀的自然概率，不是保证崇高的预言物品概率。稀有词缀的r更高，也更容易到崇高阶数，因此不能拿同概率二项分布代替真实词缀池。

自然T6要求ilvl≥55，自然／强制保底T7检定要求ilvl≥90。初始raw rarity1／2还有95%阻止自然崇高的检定；不兼容T6的词缀还须检查 `t6Compatibility` 和装备词缀效果修正。

## 保证崇高和词缀数量

实际先后顺序：

1. 决定初始raw rarity、词缀数及是否保证崇高；观星台稀有转崇高判定在自然词缀生成前进行。
2. 逐条选择合法词缀、生成自然阶数。
3. 应用镜片。
4. 进行适用的需求等级校正；ilvl100不因此压阶，词缀需求等级计算上限90。
5. 执行适用的“保证崇高”后处理。

保底不是“先放一条T7，再独立抽另外三条”。若已有m条T6／T7，对每条各做一次70%检定，任一次成功即结束保底；全失败后，从**所有现有槽位**均匀抽一条。抽到已有T6／T7也结束；抽到低阶才写T6，再以对应b检定T7。

对本报告全部允许T6的戒指池，N条词缀中额外提升一个低阶槽的机会为 `0.3^m × (N−m)/N`。不能改成只抽剩余低阶槽。其他部位若有不兼容词缀，另有按列表顺序扫描替补的路径，本模型未将它冒充通用规则。

实际 `0121 Exalted Ring` 用 `RarityGroup.Exalted=5`。桥接方法先以0.5%取raw rarity1；失败才以1%取2；再失败才以40%取3，否则取4，全部保证崇高：

| 实际词缀数 | 生成占比 |
|---|---:|
| 1 | 0.500% |
| 2 | 0.995% |
| 3 | 39.402% |
| 4 | 59.103% |

`RarityGroup.ExaltedWith4Affixes=6`才固定四词缀。主表按四分支加权，没有误算为固定四词缀，也没有重复叠加观星台25%稀有转崇高。

若额外限定四词缀崇高戒指，无镜片恰好双T7为0.053392%，优质为0.535389%，与主表不同。

## 自然掉落对照

限定：100级、非巨石、无额外稀有度修正、无指定稀有／崇高保底的普通随机戒指；排除暗金／套装后，以**最终已成崇高的戒指**为分母。满级观星台一行包含25%稀有转崇高。

| 自然生成基线 | 恰好1T7，占崇高 | 恰好2T7，占崇高 |
|---|---:|---:|
| 无观星台加成 | 7.707142% | 0.004933% |
| 满级观星台 | 22.489454% | 0.045669% |

不能把这张表叫作所有巨石自然崇高的统一掉率。`RollRarity`的巨石分支受额外稀有度影响，增加重抽并取较大roll；怪物／宝箱指定稀有或崇高来源也改变入口。不同部位、职业限制、腐化后处理和保证特殊词缀T7应分别固定输入。

[官方1.5预言奖励说明](https://lastepoch.com/1-5/patchnotes/#prophecies)中的冠军／实验保证T7奖励属于另一入口，本主表没有混入。它们至少已有一条T7，须另算双T7。

重算：

```powershell
python -X utf8 scripts/analyze_t7_lens_probability.py
```

脚本先按真实权重、同ID不重复、最多两前两后选择词缀。少于四条用动态规划保留前后缀数量和之前选择的相关性；四条时两类各取两条，可分别加权无放回抽取。再枚举全部阶数组合，应用镜片与保底；保底对单槽T7机会是线性的，因此可保留E[b_i｜原始阶数组合]精确积分身份。

验证包括各分支归一、6词缀独立小池完整身份枚举对照（最大差异低于1.3×10⁻¹⁵）、独立逐件模拟各镜片500万件（恰好1T7／2T7均在2.30个标准差内）。见 [模型验证](../analysis/t7-lens-model-validation.json)。这些是模型检查，不是客户端采样。表采用名义设计概率，忽略float32随机数端点的微小离散差异。

游戏内LensFarmingEfficiency.ExaltedTier7Probability仅为固定槽数、同分布的效率估算辅助，不输出完整恰好1T7／2T7联合分布，本报告未直接用它代替实际生成逻辑。
