# Strict提取结果：Raxx变量审阅结论

本轮仅从两份用户提供的Strict提取BD情报，再匹配Raxx填空入口。没有运行旧filter生成器，也没有生成或更新任何最终XML。

本次默认Flay为主、Skeleton为副；共享按主处理，两者同等收集。角色身份只作为情报归属，颜色尚未写入filter。

## 先审阅的结论

1. 稀有共通暗金：保留R15原143项。
2. BD关联暗金：两份Strict各11种，共20种（共享253／416）；原R15缺9种：奥诺斯·图尔的紧身衣（8）、空心手指（66）、斗争容器（241）、双纽线天平（269）、被抹灭侍祭的野心（300）、叛徒之舌（342）、血法师之握（372）、猪猡的珍珠（374）、不息狂怒（477）。其余目标已在R15，无需重复加入。
3. 本轮没有增加正文中的5种替代暗金，也没有导入Planner JSON中的精确神像组合；这些不是Strict直接导出的情报，另列后续核对。
4. 19份部位T7池作为BIS候选，19份T6池作为T6候选；Raxx宽T7素材策略单独审阅。
5. 6份Strict神像混合池、6份单词缀池提供尺寸／底材／词缀关系，不能声称已获得精确前后缀配对。
6. Strict的LP分层、FP52、全等级T6、常驻单词缀／Weaver／反伤、祭坛合计阶数分层不会直接移植。

以下变量与[变量总表](RAXX_VARIABLES.md)对应，X编号为各Strict文件的XML物理位置。原门槛见变量总表；来源门槛仅作为证据，不代表采用。
