# 追心手里剑：玩家XML需求审阅

2026-10-18加入独立官方模板，名称“追心手里剑”，稳定id为`heartseeker-shuriken-marksman`。默认未勾选，可与其他BD组合并独立编辑、保存、指定主副；与冰追心各有自己的需求，不互相覆盖。已有个人保存不会自动插入新BD，可应用新模板组合，或导入[终局需求JSON](../requirements/heartseeker-shuriken-marksman.endgame.json)。[练级需求JSON](../requirements/heartseeker-shuriken-marksman.leveling.json)独立留空。

来源为玩家粘贴的`Shuriken Marksman`过滤器，原描述为BinaQc's Very Strict。[冻结原XML](../sources/builds/maxroll-shuriken-marksman-very-strict.xml)共137条，SHA-256为`9a79e7351c3a114e746839a4fd8e605cfc8ffc53ab59cfbe1bf17e0ab4312cdf`。以下X编号是原文件的物理位置；原文件没有Order字段，未凭空补写源优先级。

## 提取边界

采用现有Maxroll导入器，只从已启用的BD专用规则提取：X127明确暗金名单、X67–76部位T7、X24–25与X28–36神像、X57／58／60／61／64／78祭坛，共28条源规则。原LP、T6／T7、未腐化、总阶数、声音、颜色与隐藏策略保存在原XML；模板只保存目标，由工作台现行基底重新生成。

未把通用暗金、暗金神像、职业T7广池、Rune of Havoc、通用祭坛及Alt Leveling混进本BD目标。关闭的一项目标神像规则及通用永恒手套入口没有额外扩大目标底材。来源没有已启用的独立普通制作底材需求，终局05为空。

X65“Exalted Bases for Alt Leveling Setup (T7)”和X27反伤神像属于来源的通用小号准备规则，未提供本BD的独立练级路线；不据此推断0–79级装备目标。XML中各词缀列表顺序保留供玩家调整，未宣称它等于作者的需求优先级。

## 验证与复现

独立85条；与冰追心组合，手里剑为主116条、冰追心为主114条；与旧Strict两BD组合134条；与Allie＋835组合177–179条。四份新来源全部启用206–210条，六份全部启用234–251条，沿用超过200报错且不截断。

全套73项测试通过。新增审计覆盖27组组合、22个装备／祭坛目标案例及45份原有来源、需求、基底、引擎和历史XML字节保持；检查六模板默认状态与两阶段JSON往返。打包Pyodide WASM在Node下核对六模板及5组完整生成输出，与本地Python逐项相等。记录见[目标及组合验证](../analysis/shuriken-marksman-validation.json)、[打包引擎对照](../analysis/shuriken-marksman-wasm-validation.json)。这些是XML、数据和匹配模型检查，没有运行游戏客户端或验证真实掉落。
