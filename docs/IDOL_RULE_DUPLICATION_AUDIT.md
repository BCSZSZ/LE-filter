# 神像同名规则与生成器核查（旧输出记录）

后续已按玩家明确约定改为“同BD、同形状、同目标数量分组最多一条”，57／59已合并，玩家文件142→126条。现行生成策略、交付与验证见[神像按形状合并目标](IDOL_SHAPE_RULES.md)。下文保留按原条件逐条核查及仅更名阶段的记录。

2026-10-24。核查对象为玩家提供的142条XML、截图中的57／59条，以及当前`tool/engine.py`。编号按`Order + 1`读取，与游戏列表一致，不按XML物理行号定位。

## 57／59的实际差别

两条存在部分匹配重叠，各自仍有独立用途，不能直接删除一条。

| 规则 | 类型与底材 | 普通目标池 | 数量要求 |
|---|---|---|---|
| 57 | 巨型神像`IDOL_1x4`，底材4／9 | 470投掷物理伤害、763游侠反曲几率与弓箭伤害 | 至少一项，阶数不限 |
| 59 | 巨型神像`IDOL_1x4`，仅底材9 | 上述两项，另有480提高护甲粉碎持续时间 | 至少一项，阶数不限 |

冻结词库中，4名为“巨型暗影神像”，9名为“异端巨型暗影神像”。词库保留旧／隐藏条目；这里使用其ID和名称解释XML，不据此判断当前掉落状态。

- 底材4只有470：57匹配，59不匹配，删57会漏收。
- 底材9只有480：59匹配，57不匹配，删59会漏收。
- 底材9只有763：两条都匹配，由更前的57提供提示，59不会额外播放一次提示。

30／32是对应的“两普通目标”层，也保留不同底材／目标池。一项层与两项层分别负责开始／灵感提示，不能按神像类型相同便合并。

## 其他同名项

完整文件有34条BD神像规则，11组同名标题。逐组检查目标、底材和计数后，没有完全相同的BD神像谓词，也没有被前方一条神像规则完整覆盖的后续神像规则。

| 示例 | 关系 |
|---|---|
| 53／60宏伟神像 | 底材14有重叠；53另覆盖10–13，60另保留492 |
| 52／61大型神像 | 52为底材10–14，61为9；底材不相交 |
| 56／64厚实神像 | 分别为编织者底材1、拉贡底材0，普通目标池也不同 |
| 38／39与90／91中型神像 | 分别为拉贡底材0、编织者底材1，对应两项层和一项层 |

全文件仅66／116有完全相同的匹配条件：先驱者之针344的BD提示与通用保护。按[通用规则固定约定](COMMON_RULE_STABILITY.md)，通用规则完整保留，前方BD规则负责身份提示。这一对属于明确保留的重复条件。

## 来源与生成逻辑

57的底材4／9与470／763，以及52／53的旧范围，均与冻结的[旧Strict来源](../sources/builds/maxroll-shuriken-marksman-very-strict.xml)一致。玩家提供的方案还包含扩展目标组，与[当前四profile预设](../requirements/heartseeker-shuriken-marksman.endgame.json)不同；例如当前巨型神像目标为底材9、470／763／462。XML本身不能恢复全部编辑历史，不能断言每个差异都来自哪一次操作。[已有方案持独立副本](TOOL_GUIDE.md)，更新预设不会覆盖保存目标。

生成器核查结果：

1. 每个神像目标组分别输出一项层与两项层，两项层使用实际`pair_bases`，一项层使用`bases`。没有按词缀配对枚举规则。
2. `remove_shadowed_targets`只在前方规则完整覆盖后方范围、目标计数及其他条件时省去后条；范围相交不足以触发删除。
3. 最后的等价谓词合并与BD装备范围合并保持原边界，通用保护独立保留。神像不同范围、不同两项目标池没有被混成一池计分。
4. 标题原来只拼接“巨型神像”等类型名，省略底材，造成不同条件在游戏列表中完全同名。这是本次确认并修复的问题。

一项层有些相交条件可以通过重新拆分范围或词缀池减少重叠，但并不自动减少规则数。不同两项池若直接取并集，可能让分别属于两组的词缀凑成两项目标，改变原要求。此次修复仅更名，全部匹配条件与原有压缩策略保持。

## 修复与交付

[生成器](../tool/engine.py)在完成原有去重后，为BD神像规则写入实际底材名称；不限底材明确标注。相同底材名称仍有不同目标池时，再附底材／词缀ID区分。两项层标题读取生成后实际范围，避免误用一项层底材。通用规则名称保持原样。

玩家原文件的[更名副本](../outputs/idol-rule-audit-2026-10-24/LE-filter-idol-labels.xml)仍为142条，只改34个神像标题，原顺序、目标、底材、计数、开关、颜色、声音、图标、光柱及其余XML字段逐字段一致。57／59分别显示“巨型暗影神像、异端巨型暗影神像”和“异端巨型暗影神像”。
