## 看见不同提示时做什么

| 提示 | 含义 |
|---|---|
| 粉色，名称FLAY | 巫妖装备、素材或神像需求 |
| 蓝色，名称NECRO | 骷髅死灵需求 |
| 薄荷绿，名称SHARED | 显式共同需求、相同条件合并或Strict通用神像候选 |
| 大写／Begin提示音 | T7候选、目标配对神像、部分祭坛及核心暗金潜能层，优先检查 |
| 原色、金黄等其他提示 | Raxx通用传奇、珍贵暗金／套装、T8、双崇高、资源与开荒保护 |

颜色区分用途，大写、音效、光柱和图标提示检查优先级。T7／重要神像的光柱、图标沿用Raxx模板，光柱颜色不必与BD文字相同。普通T6、单词缀神像、拆解及任意阶腐化候选采用静音并关闭强光柱。两个BD使用相同质量层的声音，靠文字颜色区分。

所有收集目标都以并集保留。只有最后G187隐藏未命中的物品，没有位于中间的启用职业隐藏。重叠物品取第一个匹配规则的样式，看到粉色不代表死灵不能用，看到Raxx金黄也不代表它不属于BD。具体G编号查[成品索引](GENERATED_RULE_INDEX.md)。
