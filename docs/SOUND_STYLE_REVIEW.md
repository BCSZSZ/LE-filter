# 四档声音、显示与规则整理：审阅结论

本页审阅对象是原138条v2，修改结果是[当前v3 XML](../filters/Flay-Mana-Lich+Skeleton-Necromancer-v3.xml)。旧G编号只在下表用于定位旧问题；当前每一条的实际声音、图标、光柱见[全部162条提示索引](CURRENT_ALERT_INDEX.md)，完整条件见[逐条规则](CURRENT_RULES_REVIEW.md)。

四档是用户指定的四种音效；另外保留静音档。声音选择不等于给每条设置音量：当前XML有SoundId，没有逐条音量字段。未实际听音、未验证客户端响度。更好的物品通过音效、图标和光柱尺寸区分。

2026-10-07最新分档：至少3条T7彗星；双T7中至少一条是对应部位BD目标T7，灵感；其余任意双T7，开始。四T7不另设一层，包含在至少3条中。双T7目标层按现有19份BD／部位池绑定，共享先走主；两条T7之外只有低阶BD目标，不触发灵感。

T8本身最多铁匠，取消原v3的置顶彗星提示；当前为G84保留兜底。C1／C2／C3／C4只把恰好7阶计作T7。T8＋一条T7不是双T7，T8＋两条T7不是三T7；若同时有BD目标T7，按该T7提示。原Raxx的R37是Begin音效（SoundId=6），置顶彗星是v3初版新增的错误判断，已撤回。

BD指定规则的文字和光柱保持主粉、副蓝；共享名单项并入主。标签粉8／蓝12与光柱粉11／蓝15是不同的ID表，不能复用同一个数字。静音BD过渡规则仍保留身份文字色，但没有图标和光柱。

通用高潜能、T8、多T7等规则先匹配时，使用上表通用档色，不再判断主副归属。地图图标是游戏预设类别图标，不能用其ID来指定任意RGB颜色。

静音明确设置SoundId=1、MapIconId=1、BeamOverride=true、BeamSizeOverride=NONE。v2的MapIconId=0表示“默认”，不是“无”；因此旧静音项可能仍有游戏默认图标。这里修改的是过滤器配置，客户端的实际显示和固有掉落声仍待核对。

静音不再统一灰色／白色，不额外设置recolor、color或强调。基底资源原来不改色的继续不改色；基底自定义色和BD粉／蓝仍保留。光柱关闭时保留原BeamColorOverride编码，不新增无效颜色覆盖。

## T6的目的与压缩边界

T6是角色0–84级的配装过渡：不用等T7才看见对应部位的BD目标词缀。它不代表终局最佳，也不是收藏任意双T6；达到85级时，该层自动不匹配，UI的启用勾选不会自动取消。

匕首和单手斧的主BD池完全相同，都是2／718／943，其他条件也相同，所以可以合为一条。其余17个池不同，等价压缩只能达到18条。直接把所有目标合成“主一条、副一条”会产生跨部位匹配，例如把主BD武器目标718当作头盔目标；这不等价。若要删去过渡层或采用全局宽池，那是新的收集策略，不是无损压缩。

当前18条按主9条、副9条连续排列，全部静音且无地图图标／光柱。达到85级仍显示的T6，可能来自C3（目标T6＋另一条T7）、实验词缀、拆解、底材等其他入口。

## 本轮范围变化与未完成的语义

- LP=1／2从原潜能名单扩展为任意暗金，来自本轮“任意单孔／双孔”的要求。
- T8池由946补全到1156，现仅铁匠兜底。T7四类改为恰好7阶，排除T8的计数和替代；含T8的其他装备仍由独立T8层保护，T6收集范围不变。
- 其余改动是名称、排序、等价合并与显示提示；没有新增骷髅常驻单目标神像、没有替玩家决定891备用组合、没有把祭坛宽池两项定义成毕业。
- 通用传奇灵感档不按T7数降档；其中至少3条真正T7先走彗星。T8不贡献T7数量。T7计数仍未做封印／特殊附加词缀客户端实测。
- 有限离线案例及其数量见[当前验证报告](../analysis/current-filter-validation.json)；它们是源条件比较、提示字段校验与有限匹配案例，不是掉落或听音实测。
