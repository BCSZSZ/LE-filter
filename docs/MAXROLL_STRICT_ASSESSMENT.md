# 两份 Maxroll Strict filter 的参考价值

结论：**可以作为重要参考。它们补齐了“目标配装应该怎样转成拾取条件”的具体做法，现有JSON、巫妖正文和这两份XML已足够支持双BD收集试版。** 生成时仍要结合玩家进度调整替代品、素材和严格度；死灵正文可继续补充机制依据，不再是终局收集初版的必要前提。

本次只解析和评估参考文件，未生成合并成品。用户附件按字节保存，哈希见 [来源记录](../sources/builds/maxroll-strict-manifest.json)。完整条件及显示字段见 [机器索引](../analysis/maxroll-strict.json)，全部规则的位置见 [规则索引](MAXROLL_RULE_INDEX.md)。

名字分别写明两个BD；description均为BinaQc's Strict，推荐刚进入Empowered Monolith，通常隐藏低LP／WW暗金、多数稀有装备与套装。**这是生成器采用的拾取策略，不是玩家已经成型或应采用同样严格度的证明。** 全文件的大型通用名单也不是每个BD都要收集的需求。

两份lootFilterVersion都是9，lastModifiedInVersion都是1.0.0.4。用户保存的Maxroll应用代码把1.0.0.4设为该字段默认值，因此不能只凭它判定文件来自旧赛季。XML没有导出时间、原Planner阶段或生成器版本；也没有Order字段。本研究X编号仅代表XML物理位置，不沿用Raxx的Order编号。社区导入器按XML反向读入规则，是预期次序的辅助证据，客户端尚未验证。

与Raxx只涉及的ID相比，额外44个词缀与41个暗金ID已用同一批冻结的Last Epoch Tools 1.5.0数据补齐，存于 [补充映射](../sources/builds/maxroll-reference-supplement.json)。没有改写原Raxx参考表。旧物品名字可映射不等于当前一定能掉落。

## 最值得采用的具体规则

**按部位收集素材。** 巫妖X49–58与X62–71、死灵X61–69与X73–81分别提供T6／T7收集路径。共同结构是：正确物品类型、至少一条所选词缀达到T6或T7、OnlyUncorrupted；通常不限定素材底材。这与“毕业暗金本身＋制作素材分开”的判断一致，也证明T7毕业目标不要求把全部T6隐藏。

|---|---|---|
| 巫妖头盔、胸甲 | 魔力34、提高生命52 | X56／69、X55／68 |
| 巫妖手套 | 魔力34、近战攻击速度2 | X52／65 |

| 巫妖戒指 | 智力502 | X50／63 |
| 死灵头盔 | 共享流血几率406、共享流血持续时间407 | X68／80 |
| 死灵胸甲 | 共享流血几率406 | X67／79 |
| 死灵双手斧 | 召唤物持续伤害98、你与召唤物物理穿透719、所有属性50 | X69／81 |

表格是重点摘录，完整列表还包含腐化属性，见机器索引。列表内“任意一条达标”不等于每条都必须有，更不等于所有部位能共用一个无类型限制的词缀池。

**补充候选暗金。** 巫妖名单在原JSON之外加入Immortal Vise415，与正文手套升级说明一致。死灵额外加入遗物Ambitions of an Erased Acolyte300和戒指Unsated Rage477；可作为候选需求，但XML没有解释使用阶段或必要性，不称为已经确认的核心装备。

**Planner暗金本体有兜底。** 巫妖X121、死灵X132指定上述名单与UNIQUE／LEGENDARY／SET，没有LP／WW门槛；另有传奇与腐化兜底。它们之后的1／2／3LP及WW门槛用于分层提示，不能据名称推断所有核心装备都要至少1LP。

**神像与祭坛已有具体选择。** 巫妖主力神像池843／854／1070／1069、点燃神像池876／886／1070；死灵有小型、谦逊、大型与Omen神像的不同类型和词缀池。Strict条目通常要求池中至少两条；同时还有启用的“一条需求词缀”与通用Weaver路径。祭坛也有类型和T6／T7门槛，可作为具体实现参考。

**死灵有普通装备过渡候选。** X28–32给双手斧、头盔、鞋、手套、戒指限定底材，要求所选词缀至少两条、合计阶数至少4。它们没有RarityCondition；名称Rare Strict不证明只匹配RARE。这些候选有助于补过渡收集，但不足以说明五件普通装备就满足BD成型条件。巫妖没有对应的Rare Strict条目，不能据此断言所有普通装备都无用。

**材料和制作规则可以借鉴。** 两份都在角色等级0–60收生命词缀52、0–80收T3+生命，范围含上限；死灵另收36／825／945，以及192／406／407／623职业词缀。巫妖的Edit Affixes目前只选36，不包含魔力34或暴击避免97，需要结合碎片库存配置。T7高制作潜能规则明确FP≥52、NotSealed，比单纯按名字判断制作胚子更具体。

## 合并前必须修正或确认的地方

1. **巫妖替代品未全部进入Planner名单。** 正文推荐的353／348／294／125／366均不在专属名单中，但通用规则有不同保留路径。353、125、366有不要求LP的专门通用路径；348的普通暗金潜能路径从LP2开始，294只有LP3／LP4路径。普通低LP、没有特殊稀有度或其他保留条件的替代戒指存在遗漏风险。仍需要它们时，应补明确的BD用途保留规则，不能笼统声称“完全没保护”或“都已覆盖”。
2. **神像池不是严格配对。** 将普通与腐化词缀放在同一池，数量2不能独立表达“普通前后缀必须完整”或“必须带特定腐化”。腐化是否参与数量也需客户端验证。巫妖正文的876＋891虚弱备用组合没有单独规则；891在通用Weaver池中，所以不据此断言一定隐藏，但它的机制用途与提示没有独立表达。
3. **腐化属性和制作素材要拆开。** 例如巫妖项链池含1084“智力转疯狂”，同时要求OnlyUncorrupted。该条的存在不证明腐化成品能通过它；核心Exulis有其他暗金路径。同样不能把951／1009／1022等腐化属性当作普通素材都能制作或转移。生成时按来源和用途分别处理。
4. **高级开关与多个条件都要保留。** Wanted Affix & Tier 7（巫妖X31、死灵X42）先要求一条目标词缀但advanced=false，再用另一份AffixCondition要求任意所选T7，并要求未腐化及FP≥1。目标词缀本身不必T7，同一条目标T7也没有被禁止同时满足两份条件。不能只读取保存的comparsionValue=7或只保留一个AffixCondition。
5. **Strict仍会宽收某些神像和制作物。** 通用Weaver规则选66个词缀、数量2；一条目标词缀神像规则也启用。Strict不是所有物品都要求精确毕业配对，也不是完全隐藏低阶普通装备。
6. **23条关闭项是功能选项。** 包括CoF升华底材、通用神像／祭坛、普通暗金／套装及某些制作素材。不能套用Raxx“56条蓝字是说明”的删除策略；颜色蓝也可用于真正的拾取规则。启用CoF升华规则前要选择物品类型，调整Edit Affixes前要确认库存。
7. **两份不能直接拼接。** 它们重复通用保护和末尾隐藏逻辑；加在另一套BD规则之前的隐藏规则可能截断后者。官方说明规则顺序会决定重叠物品的显示结果。[EHG规则说明](https://forum.lastepoch.com/t/loot-filters-in-last-epoch/24302) 项目当前固定的200条上限下，仅两份就有271条；再加Raxx去掉说明后的107条，会有378条。应提取BD需求填入Raxx框架，重新定义顺序和提示，再验证两BD同等保留。

## 后续采用方式与玩家待办

资料分工明确：Raxx提供通用框架与珍贵物品保护；Planner JSON说明目标成品和实际词缀组合；Strict XML提供拾取与制作门槛候选；攻略正文解释依赖、替代品与升级条件。三者有差异时先记录，不自动把生成器输出当最终答案。

生成双BD试版时，需要完成这些配置：

- 保留两套核心暗金，以及当前仍需的替代／升级暗金；新增300／477的使用原因暂标来源为生成器候选。
- 按部位并集收集两BD素材，分别保留神像的组合与腐化用途；补巫妖备用点燃＋虚弱方案及41:4祭坛选项。
- 选择T6／T7收集范围、低阶碎片规则与升华素材；Strict阈值作为可采用的参数，不自动替代玩家库存和进度判断。
- 设置共同需求、巫妖需求、死灵需求的提示，保证收集等优先级；重复物品仍由首个命中的规则决定提示。
- 配置Raxx全部采用的空模板后，删除其56条说明并明确Order；保留有用途的关闭功能规则。导入检查、0LP核心、低LP替代品、神像数量与腐化匹配仍需客户端验证。

复现：`python -X utf8 scripts/analyze_maxroll_filters.py`。脚本只用标准库，离线校验原文哈希、解析全部规则、保留重复对象和nil、检查全部ID引用及Planner暗金覆盖，并重建两份索引，不修改任何原始来源。
