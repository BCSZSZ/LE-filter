# Raxx原版：需要填写或审阅的变量

由extract_raxx_variables.py读取冻结原版后生成。R编号=原版Order+1。本表只登记变量和原始默认值，没有给出最终filter。

## 本轮保留的原版收集策略

1. 稀有共通暗金：R15原名单143项保留，0LP也留。
2. BD关联暗金：把目标名字补入同一个R15名单，0LP也留；不新增BD独立LP分层。
3. 高潜能暗金：R12不限制名字，LP3／WW20起；R13／14仍用原名单与LP2／WW17、LP1／WW14门槛。
4. 传奇、套装与资源：R8全部传奇、R16需要的套装、R19–24资源沿用原版。
5. 装备：BIS目标与宽T7制作素材分开；双崇高至少两条T6且没有等级退出；只有R63／64的T6过渡补充收集在85级退出。
6. 神像：BIS默认至少两项；过渡神像分别90／75级退出；祭坛R127至少一项、阶数不限。
7. 早期腐化：R75只收已选腐化属性、角色0–59级；不添加全等级宽松腐化分支。
8. R37的T8池与R163最终隐藏沿用原版，本轮不扩池或增加规则。

## 每个入口的原值与保留门槛

### V01｜BD暗金名单

可填字段：UniqueId名单；保留原珍贵名单。

处理原则：Strict只提供目标名字。补入R15后采用Raxx的无潜能门槛保护，不新建BD的1／2／3LP层；不删除原珍贵物品。

- R15（启用）：未限定类型；底材不限／未选；词缀池=无；名字名单=143项；没有额外阶数／等级门槛。

### V02｜需要的套装名单

可填字段：UniqueId名单。

处理原则：只按冻结数据库的物品类型分开套装；导出名单里的SET字样不能证明每个名字都是套装。

- R16（启用）：未限定类型；底材不限／未选；词缀池=无；名字名单=21项；没有额外阶数／等级门槛。

### V03｜中低潜能名单的取舍

可填字段：保留／删除哪些名字；潜能门槛不变。

处理原则：Strict能证明需要哪些物品，不能证明其余412项都不要。保留原LP2／WW17及LP1／WW14门槛。

- R13（启用）：未限定类型；底材不限／未选；词缀池=无；名字名单=412项；稀有度=UNIQUE；潜能配置=MinLegendaryPotential:2/MinWeaversWill:17。
- R14（启用）：未限定类型；底材不限／未选；词缀池=无；名字名单=412项；稀有度=UNIQUE；潜能配置=MinLegendaryPotential:1/MinWeaversWill:14。

### V04｜职业隐藏

处理原则：Strict未给出玩家永远不玩的职业。不能自动将主套路之外的职业排除；原R29关闭。
