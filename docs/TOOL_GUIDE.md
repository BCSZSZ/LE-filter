# 目标工作台使用说明

这个工具把BD目标填入我们审阅过的Raxx基底。多选已有模版、指定一个主BD，点击“用所选模版新建方案”创建一份包含全部选择的可编辑方案，预览后导出XML；可以保存并切换多套组合。

## 在线使用

打开[GitHub Pages工作台](https://bcszsz.github.io/LE-filter/)，首次等待运行环境加载。网页支持Maxroll filter文件／XML文本、共通需求JSON，以及[LETools角色profile多链接并集导入](PROFILE_IMPORT.md)。LETools角色链接通过后端从Maxroll公开角色API读取，无需书签或转存Planner；提取与生成计算在浏览器内完成。配置保存在当前浏览器，跨设备用顶部“保存配置”备份，再从“更多→导入方案备份”追加恢复。

左侧并排“已有模版”和“我的保存”。已有模版提供六个独立BD：旧Maxroll Strict的Flay／Skeleton，以及Allie Flay攻略／中文流血骷髅835攻略／冰追心／追心手里剑。冰追心当前终局目标以2026-10-18玩家导出的`LE-filter (10).xml`为准；追心手里剑为玩家提供的`Shuriken Marksman` Very Strict XML与四个指定天梯角色的并集，稳定id为`heartseeker-shuriken-marksman`，与冰追心独立，练级同样留空；来源边界见[冰追心审阅](ICE_HEARTSEEKER_PLANNER_REVIEW.md)及[手里剑审阅](SHURIKEN_MARKSMAN_REVIEW.md)。四份新来源模板默认未勾选。已有模版栏支持多选，主BD只能在已勾选项中指定；取消主BD时自动改选另一项。首次预选旧Strict两BD，但“我的保存”为空。勾选、改选主BD都只改变待应用的选择，当前保存与编辑不受影响。

点击“用所选模版新建方案”，所有已选模板生成一条组合保存方案，包含各自两阶段目标、来源以及所选主BD。再次应用生成新的模板副本，不覆盖以前的保存。“我的保存”一条记录就是一套组合，点击记录直接继续编辑；两份Flay在同一方案内仍保留独立BD身份，不互补目标。

侧栏常驻三个入口：“用所选模版新建方案”“从角色链接创建”和“更多”。“更多”默认收起，包含“导入方案备份”“导入filter”“导入BD需求JSON”“导出本BD需求”，选中操作后收起。原“选择默认组合”快捷入口已删除，首次预选及已有保存仍按原状态恢复。编辑自动保存；导出本BD需求下载的是当前BD、当前阶段的目标文件；顶部“保存配置”备份全部方案，底部“导出filter”生成游戏XML。

下载JSON／XML时使用Chrome或Edge。Codex内置浏览器能编辑和预览，但测试中不能正常接收浏览器内生成的下载文件。网页版本不需要安装Python或启动本机服务。

开发者运行`python -X utf8 scripts/build_pages.py`生成`.site/`，只用静态HTTP服务即可预览。GitHub Actions执行测试、打包和部署；固定Pyodide 314.0.7的必要运行文件一起发布。浏览器与本地复用`tool/engine.py`和`tool/requirements.py`，不另写一套过滤策略。

## 启动与保存

“共通规则”中崇高实验装备默认关闭，需要时可开启；通用暗金0LP保护与通用套装保护是两个独立开关，默认开启。当前完整池181暗金／全部61套装：暗金由旧138移出7种世界随机reroll=0、补50种正reroll暗金；套装全收，不进入暗金编号分类或reroll筛选。茧化、原限定来源及特殊奖励保留。2026-10-19起通用规则保持完整，包含已被T0或BD保护的ID，游戏按顺序首次匹配；默认Strict现98条。开关随当前方案保存、刷新和配置备份恢复；旧保存缺字段时补默认值，明确选择和BD目标保留。完整名单见[现行共通保护](COMMON_UNIQUE_PROTECTION.md)，规则边界与验证见[通用规则固定](COMMON_RULE_STABILITY.md)。

在仓库根目录双击 [start-tool.cmd](../start-tool.cmd)，浏览器会打开 <http://127.0.0.1:8765>。需要已安装Python 3及Windows的`py`启动器，无需安装Python第三方包或Node。关闭启动窗口或按Ctrl+C会停止服务。

也可以在仓库根目录运行：

```powershell
python -X utf8 tool/server.py --open
```

方案自动保存在当前浏览器中；使用右上角“保存配置”下载全部方案的JSON备份，左侧“更多→导入方案备份”追加恢复这些方案，已有保存保留。换浏览器或清除网站数据时，用JSON恢复。XML是游戏导入文件，JSON是可继续编辑的目标配置。

“我的保存”存放完整组合副本，支持重命名方案；方案内部可分别改名BD、启用／停用BD和调整主BD。旧浏览器v1配置迁入一条保存方案，含已启用与未启用的全部BD，两阶段、来源和主副设置保留；原v1存储键保留，升级后使用v2键。旧版本整套JSON也可载入为一条方案。模板更新不会覆盖已有方案，需要新版默认目标时重新应用模板，或点“从模板重置BD”确认后只替换当前成员的两阶段目标，名称和主副身份保留。

整套备份为`format: "le-filter-workspaces"`、`version: 2`：`saves`中的每项包含方案`id`、`name`、完整引擎`config`和当前编辑成员`active_build_id`；`active_save_id`标识当前方案，`selection`记录模板草稿的`ids`／`main_id`，`draft_config`保存尚未创建方案时的共通设置。各方案内部`config.version`仍为1，目标按`builds`归属，`main_id`只标记该方案的主BD。单BD需求JSON格式仍为version=1。导入备份为方案分配新保存ID，已有方案和模板选择保留，并打开备份中当前的方案；尚无保存记录的备份恢复其模板与共通草稿。

右上“共通规则”可独立编辑，不要求先应用BD。尚无方案时编辑共通草稿；有方案时保存到当前方案，新建模板组合沿用当前共通设置。暗金神像默认全收集：10种可选择／关闭，先驱者之针344独立常驻，不随该开关或角色等级关闭。共通选择不写入单BD需求JSON。BD明确需要的神像仍保留；通用装备／套装池不会再次兜底已取消的神像。

极稀有装备使用独立首条共通规则“**T0极稀有暗金 · 0LP起最高档**”，玩家确认只收下列6件：

| ID | 装备 |
|---|---|
| 61 | 奥利安之眼 |
| 208 | 贪婪虚空 |
| 277 | 阿特拉里亚的红戒指 |
| 473 | 永恒之池 |
| 476 | 死亡之舞 |
| 478 | 幻灵赠礼 |

名单来自项目既有version150冻结数据库的最高稀有档T0，见[极稀有名单](../sources/ultra-rare-uniques.json)。这是装备本身的掉落稀有档，不是词条T阶、传奇潜能或市场价格。独立规则仅按这6个ID匹配，不限制Rolls、LP、WW、腐化或角色等级，0LP及以上都使用最高“彗星”档：声音12、图标5、最大光柱、红色名称7与光柱10，并开启强调。彗星配色优先于主副BD身份；BD未指定或没有目标也照常保护。既有BD目标和浏览器方案保留，刷新网页后重新导出XML并导入游戏即可生效，不必重建保存方案。

任何启用BD的所需暗金引用一个套装部件时，生成器自动加入对应整个套装，全部部件沿用该BD目标的0LP保护和主副提示，LP／WW仍使用原有分档。多个BD引用同一套装时，共享部件按主BD处理。所需暗金页把补全的部件标成“套装补全”；选择器与需求JSON仍只保存玩家明确选择的目标，取消整套的最后一个明确部件后，自动补全才消失。停用BD不触发补全。冻结套装关系见[sources/item-sets.json](../sources/item-sets.json)，覆盖词库中的24套／61件，不按名字猜关系。835攻略明确25项，补齐78与170后实际收集27项；Allie17项没有套装部件，保持17项。

通用暗金、通用套装、共通暗金神像、先驱者之针344、六件T0最高档各用一份暗金条件。181暗金／61套装及共通神像所选名单完整保留，和BD／T0重合也不扣除；针的通用规则始终保留，前方BD版本可先提供身份色。只因自身开关关闭或玩家清空选择而不输出。请按类别查找规则，编号随所选BD及压缩结果变化。截图里同一规则的“170已选择＋61已选择”不是两名单相加：按[社区格式说明](https://forum.lastepoch.com/t/how-to-create-a-loot-filter/27576)，多个条件须同时成立，会求交而缩小范围。只读核对本机旧导出，两个原名单交集21、并集210，旧文件中原本为两条规则；保存的旧XML没有重现截图的同条双条件。因此不能说它完全匹配不了，也没有游戏客户端实测结论。重新从当前网页导出并导入游戏，才会更新已导入的旧filter；网页更新不会修改游戏里的文件。生成器会拒绝单条规则出现重复暗金条件。

左侧“更多”中的“导入BD需求JSON”“导出本BD需求”使用[共通需求格式](REQUIREMENTS_FORMAT.md)，保存正在编辑的一个BD、当前阶段的目标和可选来源：终局五类，练级两类。导入只修改当前方案，同id替换文件所指阶段，保留另一个阶段、启用状态和主副身份；新id加入当前方案并启用，尚无方案时创建一条导入方案。真实样本是攻略835的[终局需求](../requirements/bleed-skeleton-roamer-guide-835.endgame.json)、[练级需求](../requirements/bleed-skeleton-roamer-guide-835.leveling.json)及[审阅表](BLEED_SKELETON_GUIDE_REVIEW.md)。

## LETools角色链接导入

点击左侧“从角色链接创建”，粘贴同一BD的1–12个具体profile链接，点击“读取角色并预览并集”。读取完成后核对暗金、装备、神像与祭坛数量，点击“保存个人BD”，再预览或导出filter。默认新建个人方案，也可向当前方案添加独立BD。个人导入不改已有模版；已有保存和其他阶段保留。重复链接去重，任一来源失败、身份不符或未知ID都不生成部分并集。详细步骤及分类见[角色导入说明](PROFILE_IMPORT.md)。

## 填写与导入

1. 多选已有模版并指定主BD，点击“用所选模版新建方案”创建组合方案；也可用“我的保存”的＋创建自定义方案，或导入filter／BD需求。导入结果先核对提取数量和来源分类。
2. 标准Maxroll的目标规则自动识别；其他命名的filter可展开“核对来源规则与情报分类”，手动指定要提取的规则。通用词缀大池、隐藏规则、Strict的制作筛选不自动当作BD目标。
3. 终局五个入口的内容如下。列表支持中文、英文、ID搜索，多选时切换搜索不会丢失已选项目；可“只看已选”，也可显示旧／隐藏条目。练级切换后只显示词条与底材两份列表。

| 入口 | 填写内容与生成用途 |
|---|---|
| 所需暗金 | 按头盔、胸甲、戒指等装备部位分组展示目标暗金／套装，物品部位取冻结词库；点击“选择暗金”编辑。套装自动补全并标注；目标0LP也保留，声音沿用已确认的LP／WW分档。BD1LP用一条目标池规则，为橙色灵感；BD2LP另用一条目标池规则，为红色彗星，主副及共享目标同档。非目标2LP仍走通用灵感；六件T0始终彗星。 |
| 装备词条 | 按部位填写暗金装备需要的词条，每部位竖列按优先级编号1、2、3…，第一项最高，可拖放或用↑↓调整；此页省去底材选项和不限提示。生成目标单T7、双T7中至少一条目标T7的彗星、非目标T7＋低阶目标（85级退出）；双T7且三词条空一栏也为彗星，其余任意双T7合用通用灵感。 |
| 祭坛词条 | 独立填写祭坛底材与实际目标池，至少一项目标、阶数不限，开始档；允许显式腐化目标，例如Allie尖塔底材3＋1105。 |
| 神像词条 | 按类型、底材和普通目标池填写；至少一项开始、至少两项灵感。可以分别编辑候选层与两项层底材。 |
| 所需底材 | 首选最多一个、替代可多选；每BD／部位首选一条、全部替代一条，均需同BD对应部位目标恰好T7，常驻。 |

选择暗金时，列表按头盔、胸甲、戒指等部位分组，只需搜索和勾选。搜索支持中文、英文、ID、部位及当前展示的来源；搜索保留已勾选项目，点击“应用选择”才写入当前BD。已选的旧条目继续显示；未选的旧／隐藏项默认隐藏。

每件装备只附一个主要来源、一个固定参考值及可用图片。世界暗金用100级／命运12／无镜片的同类型通用池，按每件预言奖励计算，不计职业偏置；套装标注需套装预言。Boss固定取最高副本层级／开启者奖励的表内单次掉率上限，多次奖励不合并。特殊机制没有固定概率时保留简短说明。资料与完整原生算法见[暗金掉落资料](research/UNIQUE_PICKER_DROP_DATA.md)；页面不再展开职业、难度及多来源条件。图标加载失败时隐藏，选择与生成照常工作。

神像编辑分组标题和规则预览会显示具体底材，如“中型拉贡神像”“中型编织者神像”；底材不限时明确标注。预览搜索也支持底材名称，两项层显示它实际使用的底材范围。

装备词条优先级由各部位的`affixes`列表顺序保存。Allie沿用攻略现有顺序，其他来源沿用各自当前列表，玩家可在保存方案中调整。拖动词条或左侧握柄，在同部位目标词条的上半部／下半部放置，表示插到它前面／后面；位置线提示落点，松手后重新编号并自动保存。不能跨部位移动，↑↓仍可使用。选择器把已选项按优先级展示，原有项保留顺序，新增项排在最后；应用选择、刷新、整套备份和单BD需求导出／导入均保留顺序。这里记录目标的重要程度，生成仍按既定T7目标池匹配；同一目标集合仅调序时XML保持一致。暗金按部位分组完整保留明确目标ID列表，套装补全只影响展示和生成的匹配池。

没有来源的内容留空，不从另一来源补猜。比如骷髅Very Strict未提供定向底材，其底材栏为空；旧Strict有五组。脚部目标28／676／679全部保留；胸甲只有406，就不会添加192。攻略作为独立输入时可以记录它明确提供的目标，不能反写成Strict原本已有这些内容。

附魔与腐化另存参考。普通神像计数只使用冻结词库`specialAffixType`为0／5的源词缀；897属于附魔4、腐化为6，两者都不凑普通一项／两项。物品可以带附魔或腐化，不要求物品总词缀数为2。来源池有三项目标时，仍只生成一条“整个池至少两项”，不枚举配对。

附魔／腐化参考在对应部位下单独显示为词缀标签。例如攻略835护身符的1085／1086显示在“腐化参考”，945仍是普通目标。05只列普通装备底材，保留原R82普通／魔法／稀有／崇高范围，增加同BD对应部位目标T7条件，不加等级或锻造潜能门槛。裸底材、非目标T7、T8均不能通过05；另一BD的词缀不能配这个BD的底材。如果未填对应部位目标，预览会说明未生成该05规则。暗金用01，祭坛与神像底材各在03／04。数量来自当前BD来源，没有5项限制。

终局05分开填写“首选底材”和“替代底材”。首选最多选一个；改选或取消首选时，原首选会移入替代，候选不丢失。替代列表不包含当前首选。原文没有普通首选时可留空，全部归替代；旧filter／JSON没有排序信息时不猜首选。练级底材维持并集，不增加此分类。

Allie正文明确首选：头盔70、胸甲64、靴子11、遗物4、戒指9；手套、腰带、护身符全部替代。共5种首选、23种替代，目标保存不变。当同BD目标单T7规则已经完整覆盖所选底材时，不重复生成05；C1底材范围较窄时仍为未覆盖的首选／替代分别生成05。当前Allie完整方案88条，Allie＋835为141条，默认Strict组合98条，均启用。原有四个BD全选按主BD为169–184条；冰追心单独81条，与Allie＋835三BD组合175条，与旧Strict两BD组合132条。追心手里剑原XML版本的85条为历史数量；四角色并集经2026-10-19通用规则固定后独立100条，与冰追心组合129／131条。最新生成数量见[通用规则固定](COMMON_RULE_STABILITY.md)，六模板全选253–268条；超过200仍报错，不截断。已有保存可手动补充、导入新版同id终局JSON替换该阶段，或明确从模板重置。

2026-10-11玩家补充：Allie厚实神像分别保留拉贡底材0／点燃139，以及编织者底材1／点燃几率与点燃火焰穿透876。876属于普通special=5，一项即可进入BD提示，不额外要求抗性后缀；用户补充记录在终局JSON的source.user_adjustments中。

底材的一项层／两项层范围保留来源差异。内置Flay示例两层均收Weaver／Lagon，这是之前明确审阅的定制；再次导入原Strict会先保留它自己的底材范围，可在界面修改。

## 练级接口

每个BD的`profiles.endgame`与`profiles.leveling`互不自动复制。练级只填写一份装备词缀池和一份底材列表，不需要逐部位分配词缀，不再填写R编号。词缀按同一个BD计分，单个ID不重复计数；不同BD不能合计。程序从冻结词库的装备类型范围判断哪些部位只有一个可出现目标。

| 通道 | 门槛与退出点 |
|---|---|
| 练级品质 | 0–29级至少一项目标；30–49级目标阶数合计≥5；50–79级合计≥8；80级退出。 |
| 单可用目标例外 | 该装备类型在该BD池中只有一个可出现目标时，50–79级单目标T≥5即可。池里有多个可出现目标而当前物品只掉一项，不属于这个例外。 |
| 练级底材 | 0–29级允许指定裸底材；30–59级指定底材＋同BD至少一项目标，阶数不限；60级退出。 |
| 普通练级拆解 | 只使用填写的BD目标，沿用原T≥3拆解门槛，0–49级；50级退出。 |
| 原职业／泛用拆解 | 原R84–90名单与T4／T5门槛保留，原常驻通道改为0–59级，60级退出；职业通道按目标关联启用。 |
| 初期兜底 | 原0–9级全物品保留；删除10–29级所有稀有、未指定早期底材及武器示例通道。早期崇高原池仍在60级退出。 |

例如60级T5＋T3同BD目标可通过品质层，T3＋T2不能；两个BD各自T4不能合计8。独立底材／拆解／通用保护通道在各自退出前仍可能保留品质不达标的物品。终局目标规则全程参与，80级只退出普通装备练级层。

练级层先主BD、再副BD；每个BD内部品质层按50–79级 → 30–49级 → 0–29级排列，50–79级单可用目标例外紧跟该BD的品质规则，该BD的定向底材与拆解位于其品质层后。分段等级互斥，倒序不改变收集范围。

Raxx通用神像与腐化保留为独立规则，不掺入BD目标。R128／129仅使用原普通49项，保留原90／75退出点；R135保留其普通池中属于这些共通目标、或词库class为0／1的条目，删去职业技能专属示例，仍60退出。附魔4／腐化6不凑普通神像数。R75腐化18项均class=0，保留原60退出点；不会因为BD参考腐化而另行放宽。BD神像一项／两项规则常驻、先于通用层，主粉副蓝。

新增一条“共通抗性神像常驻”：1×2厚实神像或2×1谦卑神像，至少一条普通抗性后缀、阶数不限，涵盖拉贡／伊泰拉及编织者底材。独立于BD JSON，始终启用且不随等级关闭；静音、无地图图标／光柱，不改原标签色。BD目标层优先，原通用规则及其退出点另行保留。附魔／腐化不能单独满足此条件，但带这些额外属性的物品也不会被排除。

| 尺寸 | 普通抗性后缀ID |
|---|---|
| 1×2 | 火111、冰112、闪电113、元素117；对应召唤物复合抗性887／885／888／886。 |
| 2×1 | 腐化114、虚空115、毒素116、物理430；对应召唤物复合抗性867／868／869／870。 |

名单由冻结词库中的普通类别0／5、后缀、对应尺寸与Resistance名称确定，当前共16项。其他尺寸的抗性不通过这条共通规则保留。Allie已有模版包含2026-10-11玩家神像与祭坛补充；已有保存不会被覆盖。导入新版[终局需求JSON](../requirements/flay-lich-allie-guide.endgame.json)替换同id的终局阶段，练级与主副设置保留；需要保留当前终局编辑时也可手动补目标。

JSON接口示例（对应BD的`profiles.leveling`）：

```json
{
  "affixes": [26, 945, 98, 643, 502, 45, 28, 27],
  "bases": [{"type": "RING", "bases": [7]}, {"type": "RELIC", "bases": [15, 18]}]
}
```

练级为空时不猜目标、不沿用Raxx武器／底材示例。导入旧配置会把旧装备目标和已启用的装备R入口合并为两份列表，原始练级配置保存在`legacy_leveling`，随整套配置备份，不能把旧神像／暗金等无声挪入普通装备池。

## 合并与导出

已有模版的多选与主BD设置决定下一次新建方案的内容，应用前不会产生保存。没有选模板时不能应用，当前已有方案仍可编辑和导出。打开保存记录或刷新页面直接恢复当前方案，无需再次应用模板；方案内没有启用BD时不能预览／导出，目标仍保存。

中间顶部列出当前方案的全部BD，支持启用多项、选择一个主BD，并点击名称切换编辑各自的终局和练级需求。“添加BD”加入当前方案的自定义成员。切换标签只改变编辑对象，预览和导出始终使用当前方案全部启用BD；词缀评分仍按BD独立计算。实际首次命中顺序为彗星→灵感→主BD→副BD→通用其余档位，各BD内部高档在前。彗星统一红色7／10，灵感统一橙色5／7；其余主粉8／11、副蓝12／15，共享按主，通用开始金色4／6、铁匠金黄3／4。满足彗星条件后的其余任意双T7为灵感，先于主低阶目标；副BD两目标神像也先于主BD一目标，用灵感橙色。双T7及T0不另设颜色。静音BD仍用身份色，非BD静音不改色。所有启用BD仍全部收集。停用当前主BD时，会选择仍启用的一项。

导出只包含启用规则；关闭项及目标继续保存在配置与源模板中。条件、目标池、底材、角色和档位完全相同的BD装备规则可合并类型；不同部位的不同目标池不会混用。C1已完整覆盖的05底材不重复输出；BD1LP灵感、BD2LP彗星各合用一条目标池规则，目标池仅取启用BD并自动补全套装，六件T0由前置常驻彗星覆盖；非目标2LP仍用通用灵感。双T7含至少一条BD目标T7的彗星层，在同类型／同底材范围内合并启用BD目标池；只要求一条目标，不跨BD凑分。三词条空一栏彗星层用1前2后、2前1后两条共通规则；其余任意双T7合用一条23类灵感规则。通用规则完整保留，即使谓词与前方BD相同也输出；通用WW名单固定，名单外BD目标另用BD规则补充。BD内部仍省去共享暗金重复归属、低档T0、针的重复BD0LP及被前置目标层完整覆盖的规则。详细范围见[通用规则固定](COMMON_RULE_STABILITY.md)。

“预览规则”显示实际顺序、声音、部位、目标和门槛，可过滤查看。暗金规则可展开其完整名单，也支持按物品名字／ID搜索。终局／练级切换只切换编辑内容；“导出filter”始终生成一份包含两阶段的`LE-filter.xml`，不因停留在练级页而丢掉终局目标。成品删除原蓝色说明文字；原始资料、基底模板和历史v3快照保留。

原Raxx与赛季冻结输入保留为旧名单证据；现行通用池是181暗金／全部61套装，独立另有10种可选暗金神像及先驱者之针344。25种先古仍在通用保护中，4种赛季神像默认在可选神像规则中；神像关闭后不会被通用装备池继续显示。本次移出的赛季暗金422／460／474／480不再因“赛季新增”自动进入通用0LP池；BD明确目标与更高潜能层仍保留。旧赛季条目仍按ID匹配，无属性、词缀或角色等级门槛。低WW静音覆盖层已删除，原R12／13／14重复混合潜能规则不再生成。完整现行范围见[当前共通保护](COMMON_UNIQUE_PROTECTION.md)，[赛季源名单](SEASONAL_UNIQUE_PROTECTION.md)保留。共通选项留在整套配置，单BD需求格式不变。

| 档位 | 当前内容 |
|---|---|
| 彗星 | 六件T0从0LP起；任意至少三条恰好T7；双T7中至少一条对应部位BD目标T7；双T7且恰好三条未封印词缀（空一普通栏）；BD目标2LP；任意LP≥3；任意WW≥20。全部统一红色名称与光柱。 |
| 灵感 | 任意至少两条恰好T7（彗星条件优先）；神像两普通目标；BD1LP、非BD2LP；Raxx名单及BD目标WW17–19；一般传奇。统一橙色，先于主副BD。 |
| 开始 | BD目标单T7；神像一普通目标；非BD1LP；Raxx名单及BD目标WW14–16；祭坛一项目标。 |
| 铁匠 | BD0LP／低WW；通用珍贵／赛季暗金与套装0LP保护名单；非目标单T7＋对应部位低阶BD目标（0–84级）；原崇高实验规则；T8兜底。 |
| 静音 | 额外单T7阶段储备（0–84级）、练级品质／底材、终局05、普通拆解、共通1×2／2×1抗性神像和其余Raxx静音层。没有地图图标或光柱；BD规则主粉副蓝，通用规则不改色。 |

T7计数是恰好7阶；T8不参与双／三T7，也不冒充BD目标T7。T8本身最多铁匠，其余词缀成立更高档条件时按那些条件提示。额外单T7阶段默认保留到84级，85级自动退出，也可在界面提前关闭；非目标单T7＋低阶BD目标同样85级退出。85级后目标单T7、任意双／多T7继续常驻，避免低阶目标通过另一条单T7兜底继续显示。没有专门T6规则，T6可按普通目标评分参与练级。

三词条按游戏原生未封印前／后缀计数，已有封印词缀不占普通栏位；只有两条或满四条未封印词缀不命中空一栏条件。实现与原生代码证据见[双T7彗星判定](COMET_DOUBLE_T7.md)。

任意多T7的23类是全部普通装备：武器、防具、首饰及副手，包含未在BD目标中配置的装备类型；神像、祭坛与资源另有规则，不在这23类中。

超过游戏200条规则时明确报错，不截断；减少勾选BD或重复分组后再导出。未知ID会提示，生成时不能假定其词缀类别。
