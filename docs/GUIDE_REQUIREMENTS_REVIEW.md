## 读取与转换结果

以下为2026-10-07首次提取的验证快照，规则数量不代表本轮结果。四份文件均通过共通JSON适配器校验，导入网页后从保存配置读回，目标与来源均与文件相同。Allie版Flay的两个阶段还分别点击“保存本BD需求JSON”并比较，完全一致。旧Strict两BD、已有勾选状态与主套路均保持；新id按工具既有行为先作为未勾选的可编辑BD载入。

独立Flay转换107条（101启用），独立835转换116条（110启用），新Flay为主＋835为副同时转换181条（175启用），均未超过200条；全部24项单元测试通过。转换仅在内存校验，原始Raxx、冻结模板与历史XML均未改动；没有游戏客户端实测。

Flay正文中的武器虚弱429和腰带智力502因不适用部位而排除，原链接在来源快照的unmapped_targets保留。普通词缀池只纳入明确目标，泛指所缺抗性等还需手动填写。中文835继续使用明确的8项开工过滤清单；1–15级临时手打的法术伤害／流血描述没有扩成该召唤练级池。

来源链接的ID是判断依据：同名猪猡的珍珠在两文分别链接376与374，按各自链接保留，没有用名字合并不同ID。Flay神像正文有一处把装备魔力34链接到神像语境，神像使用推荐表的109，未把34混入神像池。武器724的中文名称含“腐化抗性穿透”，它仍是普通词缀special=0，不是腐化参考special=6。

复现：python -X utf8 scripts/build_flay_allie_requirements.py；python -X utf8 scripts/build_guide_835_requirements.py；python -X utf8 -m unittest discover -s tool -v。新Flay脚本仅依赖提交的解码来源快照和冻结词库；不依赖网页或.cache。
